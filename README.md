## 🧠 Sistema de workflows dinâmicos

O CrivoData permite criar fluxos de validação sem código:

- Pipelines configuráveis  
- Regras reutilizáveis  
- Templates de validação  
- Versionamento de workflows  
- Fluxos de aprovação  
- Regras de notificação  

---

## 🛠️ Stack tecnológica

### Backend
- FastAPI
- Celery
- Redis
- PostgreSQL

### Frontend
- React

### Infraestrutura
- Docker
- Kubernetes
- Storage compatível com S3
